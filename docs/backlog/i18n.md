# Backlog · i18n Content Manager (en pausa)

> **Estado: agente en pausa** desde el 2026-09-24 (decisión D7 del usuario). La interfaz se desarrolla **solo en español**
> hasta que la base de DaviLearn esté consolidada. Este archivo lista lo que habrá que traducir o revisar al reactivar
> al agente. Lo mantienen el PM y quien añada textos (UI, Backend).

## Regla mientras dura la pausa (D7)

- Las claves nuevas se escriben **en español** en `src/i18n/locales/es/<namespace>.ts`.
- En `en/<namespace>.ts` y `fr/<namespace>.ts` se añade la **misma clave con el texto en español** y el comentario
  `// TODO(i18n)` en la línea, para que `npm run typecheck` siga pasando (`en` es la referencia de tipos y
  `es`/`fr` usan `satisfies`).
- Quien añada claves apunta el archivo en la tabla de abajo (o basta con que el grep de la sección "Cómo sacar la lista" las encuentre).
- Los ejercicios (contenido de la BD) no dependen de esto: el usuario los escribe con su script (D4).

## Cómo sacar la lista al reactivar

```sh
grep -rn "TODO(i18n)" src/i18n/locales
```
